# TTT_WAPlus

I'm doing a series called "With a Plus: where I take a simple game like pong or tic-tac-toe and watch a tutorial. Then I try to add something to it in order to understand Unity programming better.

Dev Log 0 - Follow a Tutorial (https://www.youtube.com/watch?v=ST95mtDRt8w)
* Goal: End with a functional version of the game.
* Notes: It doesn't need to include the bells and whistles.

Dev Log 1 - Add a Plus
* Goal: add something to the game yourself not shown in the tutorial.
* Notes:  I went overboard on this and added completely different mechanics because I had thought about this new version of tic-tac-toe and really wanted to implement it but as a result of coming up with such a major change I was completely stuck and needed complete assistance implementing it.

Dev Log 2 - Add a Summary (in the comments)
* Goal: Read and understand each piece of code, such that you can explain it in your own words.
* Notes: Do this for each script and function

Dev Log 3: Trace the Logic
* Goal: See can you accurately follow the logic with notes and pseudocode. 
* Note: Do you understand the input, process, and output?

Dev Log 4: Create Debug Logs
* Goal: The Debug logs should reveal the logic and you should be able to confirm if you were on the right track.
* Notes: N/A

Dev Log 5: Rebuild the Project (Not all at once, but in chunks)
Goal: Attempt to rebuild yourself.
Note: Set a time limit, attempt to rebuild it in that time. Whatever you couldn't do, get assitance and finish the rebuild that way.

Dev Log 6: Repeat
